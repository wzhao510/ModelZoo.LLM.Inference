2、精度测试：
需要先启动server端，server端启动完毕后出现The server is fired up and ready to roll!，然后启动client
----------------------------------------------DeepSeek-R1-Distill-Qwen-7B-BF16---------------------------------------------------
*server: python -m sglang.launch_server --model /pde_ai/models/llm/DeepSeek/DeepSeek-R1-Distill-Qwen-7B/  --trust-remote-code --tp 1
*client: python ./code/run_ceval_client.py --model /pde_ai/models/llm/DeepSeek/DeepSeek-R1-Distill-Qwen-7B --test_jsonl /pde_ai/datasets/ceval_vllm_client/ceval_val_cmcc.jsonl

----------------------------------------------DeepSeek-R1-Distill-Qwen-7B-BF16-W8A8---------------------------------------------------
*server: python -m sglang.launch_server --model /pde_ai/models/llm/DeepSeek/DeepSeek-R1-Distill-Qwen-32B-quantized.w8a8/  --trust-remote-code --tp 1
*client: python ./code/run_ceval_client.py --model /pde_ai/models/llm/DeepSeek/DeepSeek-R1-Distill-Qwen-7B --test_jsonl /pde_ai/datasets/ceval_vllm_client/ceval_val_cmcc.jsonl
