2、精度测试：
需要先启动server端，server端启动完毕后出现The server is fired up and ready to roll!，然后启动client
----------------------------------------------DeepSeek-R1-Distill-Qwen-7B-BF16---------------------------------------------------

****** attention-backend triton *******

*server: python -m sglang.launch_server --model /external/ai/models/llm/DeepSeek/DeepSeek-R1-Distill-Qwen-7B/  --trust-remote-code --tp 1 --attention-backend triton
*client: python ./code/run_ceval_client.py --model /external/ai/models/llm/DeepSeek/DeepSeek-R1-Distill-Qwen-7B/ --test_jsonl /pde_ai/datasets/ceval_vllm_client/ceval_val_cmcc.jsonl --batch_size 10 --random_seed 0 --random_num 10 --save_dir acc_results/triton

****** attention-backend flashinfer *******

*server: python -m sglang.launch_server --model /external/ai/models/llm/DeepSeek/DeepSeek-R1-Distill-Qwen-7B/  --trust-remote-code --tp 1 --attention-backend flashinfer --enable-flashinfer-mla
*client: python ./code/run_ceval_client.py --model /external/ai/models/llm/DeepSeek/DeepSeek-R1-Distill-Qwen-7B/ --test_jsonl /pde_ai/datasets/ceval_vllm_client/ceval_val_cmcc.jsonl --batch_size 10 --random_seed 0 --random_num 10 --save_dir acc_results/flashinfer
